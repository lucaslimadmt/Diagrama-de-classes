# Diagrama de Classes — Loja

Atividade acadêmica de modelagem de um domínio de loja utilizando PlantUML.

## Conteúdo

O diagrama está definido em:

```text
atividade_diagrama/src/atividade.puml
```

O modelo contém as classes:

- `loja`
- `cliente`
- `atendente`
- `produtos_estoque`
- `pedido`
- `pagamento`

Os atributos e operações registrados no arquivo representam os elementos definidos durante a atividade.

## Tecnologia

- PlantUML

## Como visualizar

Abra o arquivo `atividade_diagrama/src/atividade.puml` em uma ferramenta ou extensão compatível com PlantUML para gerar o diagrama.

## Contexto

Projeto acadêmico criado para praticar modelagem e representação de classes.
